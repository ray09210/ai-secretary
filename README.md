# AI社員1号「秘書」スターターキット

AIに秘書役の社員になってもらうための、いちばん小さなテンプレートです。

中身は**フォルダと日本語の指示書（CLAUDE.md）だけ**で、プログラムは入っていません。

**このページだけ見れば、一周できます。** 上から順に進めてください。

## この秘書ができること

- **TODO管理** — やることを預かり、翌日に持ち越し、「今日やることは？」に答える
- **自動記録** — 会話の中で決めたこと・調べたことを、言わなくてもファイルに残す
- **相談相手** — 壁打ちや考えの整理に付き合い、決まったことだけ記録する

ポイントは、チャットの履歴ではなく**ファイルに残る**こと。だから明日も、来月も、続きから始められます。

## 先に、全体像

入れるのは4つ。**無料で進まないのは Claude Code だけ**です。

Claude Code は**無料プランでは動きません**。月20ドルの Pro プラン以上が要ります。

## STEP 1. このページから、スターターキットを落とす

**→ [ai-secretary.zip をダウンロード](https://github.com/ray09210/ai-secretary/releases/latest/download/ai-secretary.zip)**（GitHubのアカウントは要りません）

1. 上のリンクを押す（緑の `Code` ボタンではありません）
2. 落ちてきたZIPを右クリックして **「すべて展開」**。`ai-secretary` というフォルダができます
3. そのフォルダを、次の場所へ移動します

```
Windows   C:\Users\<あなたのユーザー名>\ai-secretary
Mac       ~/ai-secretary
```

**このあと開くのは、ここだけです。** Claude Code も Obsidian も、同じこのフォルダを開きます。

（ダウンロードフォルダのままにしないことをお勧めします。あとで整理するときに消してしまいがちです）

> **確認**: フォルダを開いて、`CLAUDE.md` と `secretary` が並んで見えれば成功です。
> 中に `ai-secretary` がもう1つ入っていたら、その内側のほうを使ってください。

GitHubアカウントをお持ちの方は、このページの **「Use this template」→「Create a new repository」** で自分のリポジトリとして作ることもできます。その場合は必ず **Private** を選んでください。

検索結果の上に出る広告リンクではなく、**上のアドレスのページ**から入ってください。

## STEP 3. VS Code で、そのフォルダを開く

1. VS Code で **ファイル →「フォルダーを開く」**

並ばないときは、1つ内側のフォルダを選び直してください（外側の箱を開いています）。

2. 検索に `Claude Code` と入れて、**Install**

権限モードを **オート**にしておくと、毎回「これをやっていいですか」と聞かれなくなります。
このフォルダの中にあるのは日本語のテキストファイルだけなので、まずはオートで大丈夫です。
（確認しながら進めたい方は、そのままでも動きます）

## STEP 5. Obsidian を入れて、同じフォルダを保管庫にする

**→ [obsidian.md](https://obsidian.md/)**

**Obsidian の設定は、このテンプレートに入れてあります。** 新しく保管庫を作る必要はありません。場所を教えるだけです。

1. Obsidian を入れて、開く
2. **「フォルダを保管庫として開く」** を選ぶ（**「新規保管庫を作成」ではありません**。ここだけ注意）
3. **`ai-secretary`** を選ぶ（VS Code で開いているのと同じフォルダです）

開くと **`Home`（ホーム）** が出ます。秘書が書いたものが、TODOも記録もアイデアも区別なく、**新しい順に並ぶ画面**です。「昨日なにを話したか」を探すときは、まずここを見てください。

> **Tips: ホームをピン留めしておく**
> `Home` のタブを右クリック →「ピン留め」。次に開いたときも、いつもここから始められます。

### 中身はマークダウンです

秘書が書くのは、`.md` という拡張子のただのテキストファイルです。

- `#` で見出し、`-` で箇条書きを表すだけの、単純な書き方
- Word のように書式が埋め込まれないので、**何で開いても読めます**
- あとから検索も、まとめての差し替えもできます

Obsidian は、自分で書くためのアプリとしては使いません。**書くのは秘書、読むのはあなた**です。同期の設定もプラグインも要りません。

もし左側に何も並ばなかったら、`CLAUDE.md` と `secretary` が入っていないフォルダを選んでいます。STEP1 に戻ってください。

## STEP 6. Typeless を入れる（任意）

**→ [typeless.com](https://www.typeless.com/)**

無くても進みますが、**打つ代わりに話せる**ようになると、AIに渡す言葉が自然と長く、具体的になります。

1. 落として入れる
2. アカウントを作って、マイクの使用を許可する
3. ショートカットを押して話すと、そのまま文字になります

週8,000語まで無料です。

> **Tips: 押しやすいキーに変えておく**
> 初期設定のキーは押しにくいので、`Ctrl + Enter` に変えるのがお勧めです。小指だけで始められます。

## STEP 7. 「おはよう」と話しかける

Claude Code に、最初のひとことを入れてください。

> おはよう。今日やることを教えて

サンプルの会社（架空の宿「うみねこ荘」「やまぶき亭」）のTODOを繰り越して答えてくれたら、**セットアップは成功です。**

このとき、**何とお呼びすればいいか**を一度だけ聞かれます。答えると、以後そう呼ばれます。

そのあと、こう言ってみてください。

> サンプルを消して、私の仕事に合わせて

秘書があなたの仕事について質問して、指示書を書き換えてくれます。

## STEP 8. Obsidian で、書かれた記録を見る

Obsidian に切り替えると、さっき話した内容がもうファイルになっています。

- `secretary/todos/` — 日々のTODO
- `secretary/notes/` — 決めたこと・学んだこと・調べたこと
- `secretary/inbox/` — アイデア・あとで考えること

調べものや、ひとつの話題をまとめて話したものは、**内容の分かるファイル名**で残ります
（例: `2026-08-17-今日のレシピ.md`、`2026-08-17-繁忙期の値付け.md`）。
一覧で見たときに、開かなくても何の話か分かるようにするためです。

あなたは1文字も書いていません。書いたのは秘書です。

## STEP 9. 部署を増やす

同じ種類の仕事を2回以上頼むと、秘書のほうから「部署を作りましょうか」と提案してきます。
自分から言っても構いません。

> 経理の部署を作って

すると、`secretary/` の隣に `keiri/` というフォルダができて、その中に指示書（`CLAUDE.md`）が1枚置かれます。役割・やること・書き方のルールが、日本語で書かれているだけのファイルです。

- 名前は自由です（リサーチ、広報、PM…）
- **プログラムは書きません。** フォルダ1個と、日本語の指示書1枚だけ
- 気に入らなければ、その指示書を書き換えてください。次からその通りに動きます

## STEP 10. 外の道具につなぐ（MCP）

ここから先は、慣れてからで大丈夫です。

**MCP** という仕組みで、ふだん使っている道具を秘書につなげられます。Gmail・Google カレンダー・Notion・Slack・会計ソフトなど。つなぐほど、あなたの事情を分かった上で答えるようになります。

つなぎ方はサービスごとに違うので、Claude Code に「Gmail をつなぎたい」と相談してください。

## フォルダの中身

```
ai-secretary/
├── .obsidian/               ← Obsidianの設定（さわらなくて大丈夫）
├── Home.md                  ← ホーム。書いたものが新しい順に並ぶ
├── CLAUDE.md                ← 会社のルール（全AI社員共通）
└── secretary/
    ├── CLAUDE.md            ← 秘書の指示書（役割・口調・仕事の手順）
    ├── todos/               ← 日々のTODO（YYYY-MM-DD.md）
    ├── notes/               ← 決めたこと・学んだこと・調べたこと
    └── inbox/               ← アイデア・あとで考えることの置き場
```

CLAUDE.md は Claude Code が起動時に自動で読むファイルです。ここに日本語で書いたことが、そのまま秘書の行動になります。**書き換えれば秘書が変わります。** まずは口調や記録のルールをいじってみてください。

## よくある質問

### iPad でもできますか？

**入れるところは、パソコンが要ります。** VS Code・Claude Code・Obsidian を入れる作業は iPad ではできません。

ただ、**入れたあとなら iPad だけでも続けられます。**

- Claude のアプリ（iPad にも同じ iOS 版が入ります）の **Code** から話しかける
- GitHub のプライベートリポジトリにしておくと、iPad から話した内容も**ファイルになって積み上がります**
- 読むのは Obsidian の iPad 版。同じフォルダを開けば、パソコンと同じ画面で見られます

まずはパソコンで一周してから設定してください。アプリに **Code** タブが出ないときは、プランの条件を確認してください。

### Codex ではだめですか？

**だめではありません。** どちらもファイルを書く AI で、マークダウンで出すという点は両方できます。違うのはこの3つです。

- **読む指示書の名前が違う** — Claude Code は `CLAUDE.md`、Codex は `AGENTS.md`。このキットは `CLAUDE.md` 前提なので、そのままでは読まれません
- **置き場所の考え方が違う** — Claude Code は手元のフォルダを直接さわるのが基本。Codex はクラウドで動かすのが主軸です
- **乗り換えても、記録は無駄になりません** — 溜まるのはただのテキストなので、どちらのツールでも読めます

この講座は Claude Code に合わせて作ってあります。慣れてから乗り換えるのは自由です。

## テンプレートが新しくなったときは

つまずくところが見つかるたびに直しているので、あとから中身が変わります。新しくしたいときは、Claude Code にこう言ってください。

> 更新して

秘書が最新の指示書とホームを取りに行き、**あなたが書いた記録（TODO・決めたこと・アイデア）には触れずに**、変わったところだけを取り込みます。指示書をご自分の仕事に合わせて書き換えていれば、それも残します。

ZIPを落とし直しても構いませんが、**すでに使い始めた方は入れ直さないでください。** `secretary/` の中はもうあなたの記録です。上から重ねると消えます。まだ一度も話しかけていないなら、フォルダごと置き換えて問題ありません。

## 安全上の注意

- **実データを入れたフォルダ・リポジトリを Public（公開）にしないでください。** TODOや記録には取引先名・金額などが入ります。GitHubに置く場合は必ず Private で
- 秘書はファイルを読み書きします。機密を扱う場合は、このフォルダに何を入れるかを自分で決めてください
