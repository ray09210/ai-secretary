# AI社員1号「秘書」スターターキット

AIに秘書役の社員になってもらうための、いちばん小さなテンプレートです。

中身は**フォルダと日本語の指示書（CLAUDE.md）だけ**で、プログラムは入っていません。

**このページだけ見れば、一周できます。** 上から順に進めてください。

STEP 1〜11 は講座のスライドと**同じ番号・同じ順番**です。そのうしろに、第3回「つなぐ」と
第4回「任せる」で扱った内容を足してあります。当日の画面と見比べながら進められますし、
あとから思い出すときもここに戻ってくれば足ります。

## この秘書ができること

- **TODO管理** — やることを預かり、翌日に持ち越し、「今日やることは？」に答える
- **自動記録** — 会話の中で決めたこと・調べたことを、言わなくてもファイルに残す
- **相談相手** — 壁打ちや考えの整理に付き合い、決まったことだけ記録する

ポイントは、チャットの履歴ではなく**ファイルに残る**こと。だから明日も、来月も、続きから始められます。

## STEP 1. このページから、スターターキットを落とす

**→ [ai-secretary.zip をダウンロード](https://github.com/ray09210/ai-secretary/releases/latest/download/ai-secretary.zip)**（GitHubのアカウントは要りません）

3. そのフォルダを、次の場所へ移動します

```
Windows   C:\Users\<あなたのユーザー名>\ai-secretary
Mac       ~/ai-secretary
```

**このあと開くのは、ここだけです。** Claude Code も Obsidian も、同じこのフォルダを開きます。

（ダウンロードフォルダのままにしないことをお勧めします。あとで整理するときに消してしまいがちです）

> **確認**: フォルダを開いて、`CLAUDE.md` と `secretary` が並んで見えれば成功です。
> 中に `ai-secretary` がもう1つ入っていたら、その内側のほうを使ってください。

GitHubアカウントをお持ちの方は、このページの **「Use this template」→「Create a new repository」** で自分のリポジトリとして作ることもできます。その場合は必ず **Private** を選んでください。

## STEP 6. Obsidian を入れて、同じフォルダを保管庫にする

**→ [obsidian.md](https://obsidian.md/)**

**Obsidian の設定は、このテンプレートに入れてあります。** 新しく保管庫を作る必要はありません。場所を教えるだけです。

1. Obsidian を入れて、開く
2. **「保管庫としてフォルダを開く」** の「開く」を押す（**「保管庫を新規作成する」ではありません**。ここだけ注意）
3. **`ai-secretary`** を選ぶ（VS Code で開いているのと同じフォルダです）

開くと **`Home`（ホーム）** が出ます。秘書が書いたものが、TODOも記録もアイデアも区別なく、**新しい順に並ぶ画面**です。「昨日なにを話したか」を探すときは、まずここを見てください。

> **Tips: ホームをピン留めしておく**
> `Home` のタブを右クリック →「ピン」。次に開いたときも、いつもここから始められます。

### 中身はマークダウンです

秘書が書くのは、`.md` という拡張子のただのテキストファイルです。

- `#` で見出し、`-` で箇条書きを表すだけの、単純な書き方
- Word のように書式が埋め込まれないので、**何で開いても読めます**
- あとから検索も、まとめての差し替えもできます

Obsidian は、自分で書くためのアプリとしては使いません。**書くのは秘書、読むのはあなた**です。同期の設定もプラグインも要りません。

もし左側に何も並ばなかったら、`CLAUDE.md` と `secretary` が入っていないフォルダを選んでいます。STEP 1 に戻ってください。

## STEP 7. Typeless を入れる

**→ [typeless.com](https://www.typeless.com/)**

> **Tips: 押しやすいキーに変えておく**
> 初期設定は右Altです。押しにくければ、押しやすいキーに変更しておくのがお勧めです

## STEP 8. 「おはよう」と話しかける

Claude Code に、最初のひとことを入れてください。

> おはよう。今日やることを教えて

サンプルの会社（架空の宿「うみねこ荘」「やまぶき亭」）のTODOを繰り越して答えてくれたら、**セットアップは成功です。**

このとき、**何とお呼びすればいいか**を一度だけ聞かれます。答えると、以後そう呼ばれます。

そのあと、こう言ってみてください。

## STEP 9. Obsidian で、書かれた記録を見る

Obsidian に切り替えると、さっき話した内容がもうファイルになっています。

- `secretary/todos/` — 日々のTODO

- `secretary/inbox/` — アイデア・あとで考えること

調べものや、ひとつの話題をまとめて話したものは、**内容の分かるファイル名**で残ります
（例: `2026-08-17-今日のレシピ.md`、`2026-08-17-繁忙期の値付け.md`）。
一覧で見たときに、開かなくても何の話か分かるようにするためです。

あなたは1文字も書いていません。書いたのは秘書です。

## STEP 10. 部署を増やす

同じ種類の仕事を2回以上頼むと、秘書のほうから「部署を作りましょうか」と提案してきます。
自分から言っても構いません。

> 経理の部署を作って

すると、`secretary/` の隣に `accounting/` というフォルダができて、その中に指示書（`CLAUDE.md`）が1枚置かれます。役割・やること・書き方のルールが、日本語で書かれているだけのファイルです。

部署の名前は、あなたが言ったとおりに決まります。「販売部門が欲しい」なら販売の部署、「リサーチ部を作って」ならリサーチの部署です。**決まった部署が用意されているわけではありません。**（フォルダ名だけは短い英語で揃えます。販売なら `sales/`、リサーチなら `research/`）

- 名前は自由です（リサーチ、広報、PM…）
- **プログラムは書きません。** フォルダ1個と、日本語の指示書1枚だけ
- 気に入らなければ、その指示書を書き換えてください。次からその通りに動きます

## STEP 11. 外の道具につなぐ（MCP）

ここから先は、慣れてからで大丈夫です。

ふだん使っている道具を秘書につなげます。つなぐと、こちらが貼らなくても、秘書が自分で取りに行くようになります。
つなぎ方は3つあり、下は簡単な順です。**全部つなぐ必要はありません。** いま困っている道具ひとつからで足ります。

### つなぎ方 1. MCP — 用意されている道具を、選ぶだけ

**MCP** は、道具とつなぐ差込口の決まりごとです。Gmail・Google カレンダー・Google ドライブ・Notion・Slack・freee など、
用意されているものはこれがいちばん速い。つなぐのは最初の一度だけです。

1. [claude.ai](https://claude.ai/) を開き、左メニューの **「カスタマイズ」→「コネクタ」**
2. 使いたい道具の **「連携」** を押す（何が見えるようになるかは、許可画面に出ます）
3. **Claude Code を開き直す**（動いているセッションには出てきません）
4. 日本語で頼む。例:「今日の未返信を教えて」

> **Gmail が2つ以上あるとき**: 公式のコネクタは1アカウントだけです。会社と個人を分けて使いたい場合は、
> Claude のアカウント自体を分けることになります。

### つなぎ方 2. Claude in Chrome — ブラウザを、そのまま操作してもらう

MCP が用意されていない道具や、1回きりの作業向けです。フォームの入力、サイトを見て回る調べもの、
画面からしか触れない機能など。ふだんのブラウザを使うので、ログインし直す必要がありません。

1. Chrome ウェブストアで **Claude**（発行元が claude.com のもの）を追加する
2. Claude のアカウントでサインインする（Pro・Max・Team・Enterprise で使えます）
3. VS Code の入力欄で **`@browser`** と打って、そのまま用件を続ける
4. 動きはじめると画面の上に帯が出ます。止めたいときは Cancel

> 画面共有や配信をしながら使うときは、映るものに気をつけてください。氏名・住所・電話番号の入ったフォームを
> 自動入力させると、そのまま相手に見えます。試すときはダミーのプロフィールをお勧めします。

### つなぎ方 3. API — MCP が無い相手に、つなぎを書いてもらう

Gemini のように MCP が用意されていないものは、API でつなぎます。**つなぎのプログラムは秘書が書きます。**

1. Google AI Studio で、キーを作る
2. キーは環境変数に置く（ファイルに書かない・GitHub に上げない）
3. Claude Code に「Gemini につなぐものを書いて」と頼む
4. 以後は「Gemini にも見せて」で、作ったものを別の AI にレビューさせられます

この配布ページも、Gemini に一度見てもらっています。指摘を全部は採らない、という使い方です。

## つないだあと 1. 録音から議事録を作る（NotebookLM）

録音をフォルダに置いて「議事録作って」と言うだけにします。NotebookLM の画面は開きません。呼びに行くのは秘書です。

**先に確認**: パソコンに **Python 3.11 以上**が入っていること。入っていなければ Claude Code に「Python を入れて」と頼めば入ります。

### つなぐ（最初の一度だけ）

1. Claude Code に **「`notebooklm-mcp-cli` という MCP を入れて」** と頼む。探すのも入れるのも秘書の仕事です
2. ブラウザが立ち上がるので、**Google のアカウントでいつも通りログイン**する
3. **Claude Code を開き直す**（動いているセッションには出てきません）

> **名前を言わずに「NotebookLM の MCP を入れて」と頼むと、別のものが入る可能性があります。**
> 同じ名前で呼ばれているものが複数あるためです。講座でお見せしたのは、下記です。
>
> `notebooklm-mcp-cli` — https://github.com/jacob-bd/gemini-notebook-mcp-cli
>
> 入ったあとに確かめるなら、`claude mcp list` に **`notebooklm-mcp`** という名前で並んでいるかを見てください。

うまくいかないとき用に、裏で走っているコマンドも書いておきます。

```
pip install notebooklm-mcp-cli
claude mcp add --scope user notebooklm-mcp notebooklm-mcp
nlm login
```

### 使う

1. 録音をフォルダに1つ置く（スマホのボイスメモで十分です。ファイル名も適当で構いません）
2. 「議事録作って」と言う
3. 音声が文字になり、議事録になり、名前が付いて保管されるところまで、続けて走ります

最初の1回だけ、録音の置き場所・ファイル名の付け方・議事録の形式を伝えてください。そのあと
**「スキルにして」** と言っておくと、次からは「議事録作って」の一言で同じところまで走ります。

### 知っておくこと

- **これは Google 製ではありません。** 有志が公開しているものです（MIT ライセンス）。急に動かなくなることがあります。
  公式のものに限りたい場合は、STEP 11 の「つなぎ方 3. API」で Gemini につなぐ形になります
- **話者の区別と、何分に話したかは付きません。** 誰が言ったかが要るなら、Zoom などの録画側の機能が確実です。
  人数が多い場では、録音を始めてすぐ全員に名乗ってもらうと精度が上がります
- **固有名詞は必ず間違えます。** 人名・社名・金額だけは、目で見て直してください。ここは人の仕事に残っています
- **音声はクラウドに送られます。** 学習に使わせない設定にしても、送っている事実は変わりません

## つないだあと 2. メールの添付をフォルダに入れる

毎月届く請求書や明細を、開いて・落として・名前を付けて・フォルダに入れる。この4つをなくします。

**先に確認**: ① Google の2段階認証が有効なこと ② `myaccount.google.com/apppasswords` が開けること。
会社・学校のアカウントは、管理者が止めていて開けないことがあります。その場合は個人の Gmail（@gmail.com）が確実です。

### STEP 1. アプリパスワードを1つ発行する（3分）

Gmail を読むための鍵です。Claude のコネクタ（MCP）では**添付ファイルの中身までは取れない**ので、ここだけ別の入り口を作ります。

1. `myaccount.google.com/apppasswords` を開く
2. アプリパスワードを1つ作る（名前は何でも構いません。あとで消すときの目印です）
3. 出てきた **16桁をコピーして、手元に控える**。この画面を閉じると、二度と表示されません

> **ここで画面共有を切ってください。** 16桁は、メール全体を読める鍵です。
> また、控えないまま進めると入力し直しのときに詰まります（講座では実際に1本作り直しています）。

### STEP 2. どのメールを取るかは、Gmail の検索窓で決める

ここがいちばん効きます。**いつもの検索と同じ言葉が、そのまま使えます。**

1. Gmail の検索窓に条件を打つ。例: `from:あの会社 has:attachment newer_than:7d`
2. 出てきた結果を、目で見る。**ここに並んだものが、そのまま落ちてきます**
3. その言葉を、打ち直さずコピーして渡す

動かす前に「何が落ちてくるか」を確かめられるので、「動かない」の原因を探す時間がほとんど要らなくなります。
きれいに絞りきれないものは、無理に分けずに1か所へ置いて、あとから拾えば足ります。

### STEP 3. Claude Code に、日本語で言う

プログラムが1本要りますが、書くのはあなたではありません。ソフトの追加もありません。

1. ふだんの入力欄に話しかける
2. さっきの検索の言葉を貼って、「これで出るものを落として」と添える
3. どこへ入れるかを言う（置き場は先に決めておきます）
4. 「Python で書いて」と頼む

### STEP 4. 動かして、中を見て、直す

1. 「動かしてみて」と言う。16桁はそのつど聞かれます（ファイルには残りません）
2. フォルダを開いて、入っているかを**自分の目で1回確かめる**
3. 違ったら、そのまま言えば直ります。例:「これは別のフォルダに入れて」
4. 毎朝走らせたくなったら、そう言えばパソコンの予約実行に登録してくれます

### 危ないところと、その対処

| 危ないこと | 対処（道具の側で塞いであります） |
|---|---|
| パスワードがコードやファイルに残る | 使うたびに聞かれる形にする。どこにも書き込まない |
| 読んだメールが既読になる | 読み取り専用で開く。未読は未読のまま残る |
| 変なファイル名で、よそに書き出される | 名前に混ざる記号を外す。決めたフォルダの外には書き出さない |
| 同じ名前のファイルが上書きされる | 連番を付けて、両方残す |

塞げないのは、**16桁をどこに置くか**だけです。同期しているフォルダに置かない・画面に映さない・
使わなくなったら同じ画面から取り消す。ここは自分で決めることになります。

## つないだあと 3. Zoom をつなぐ

講座で「Zoom の URL 発行まで自動にしたい」というご質問をいただきました。先に結論です。

- **リンクを自動で発行したいだけなら、Google Meet のほうが簡単です。** Google カレンダーをつないであれば、
  「◯日の午後で30分の打ち合わせを入れて」の一言で、予定と Meet のリンクが同時にできます
- **過去の会議を探す・録画や要約を読む**なら、Zoom 公式の MCP をつなぎます。ただし、つなぐまでの手間が他の道具より多いです

### つなぎ方（30分ほどかかります）

Zoom は、他の道具のように「コネクタから選ぶ」形ではつながりません。自分用のアプリを1つ作って、その ID を渡します。

1. [marketplace.zoom.us](https://marketplace.zoom.us/) → **Develop → Build App → General app**（User-managed）を作る
2. Basic Information で **「Use Public Client OAuth」をオンにする**。ここで新しく出る **Public Client ID** を使います
3. Redirect URL と Allow List に `http://localhost:8765/callback` を登録する
4. Scopes で、使うものを追加する（読むだけなら、下の10個）
5. Claude Code に登録して、ログインする

```
claude mcp add --scope user --transport http --client-id <Public Client ID> --callback-port 8765 zoom https://mcp.zoom.us/mcp/zoom/streamable
claude mcp login zoom
```

読み取りだけのスコープは、この10個です。

`meeting:read:search` / `meeting:read:assets` / `cloud_recording:read:list_user_recordings` /
`cloud_recording:read:content` / `agentic_search:read:search` / `agentic_search:read:ask` /
`docs:write:import` / `docs:read:export` / `hub:read:content` / `hub:write:content`

> **「無効なリダイレクト (4,700)」で止まったとき**は、手順2 を飛ばしています。Zoom は `localhost` への戻り先を
> Public Client の方式でしか認めません。通常の Client ID と Client Secret では通らない、という作りです。
> また `claude mcp login zoom` は、**キーボードで操作できる画面**（VS Code のターミナルなど）から実行してください。

### つなぐと、何ができるか

**できること** — 会議を検索する／録画の一覧を見る／会議の資料・要約・書き起こしを読む／Zoom Docs を読み書きする。

**できないこと** — 会議の発行。作成・更新・削除のツール自体は並びますが、上の10個には書き込みのスコープが
入っていないので動きません。

要約と書き起こしは、Zoom の管理画面で **Smart Recording と Meeting Summary が有効なとき**だけ中身が返ります。

### 会議の発行まで、自動にしたい場合

- Zoom アプリの Scopes に `meeting:write` 系を足して、`claude mcp login zoom` をやり直す
- いつも同じ部屋でよければ、**PMI（パーソナルミーティング ID）のリンク**を予定に書いてもらう
- **Google カレンダー側から Zoom を付けることはできません。** カレンダーの MCP で付けられるのは Google Meet だけです
  （Zoom のカレンダー拡張は、カレンダーの画面から作った予定にしか効きません）
- Zoom の無料プランは、3人以上の会議が40分で切れます

## フォルダの中身

```
ai-secretary/
├── .obsidian/               ← Obsidianの設定（さわらなくて大丈夫）
├── Home.md                  ← ホーム。書いたものが新しい順に並ぶ
├── CLAUDE.md                ← 会社のルール（全AI社員共通）
└── secretary/
    ├── CLAUDE.md            ← 秘書の指示書（役割・口調・仕事の手順）
    ├── todos/               ← 日々のTODO（YYYY-MM-DD.md）
    ├── notes/               ← 決めたこと・学んだこと・調べたこと
    └── inbox/               ← アイデア・あとで考えることの置き場
```

CLAUDE.md は Claude Code が起動時に自動で読むファイルです。ここに日本語で書いたことが、そのまま秘書の行動になります。**書き換えれば秘書が変わります。** まずは口調や記録のルールをいじってみてください。

## 動かないときに見るところ

講座の4回で、実際に止まった箇所です。

| 症状 | 見るところ |
|---|---|
| 拡張機能に Claude Code が出てこない | VS Code を閉じて開き直す。似た名前が並ぶときは、発行元が Anthropic のもの |
| Obsidian に何も並ばない | 「保管庫を新規作成する」を押しています。「保管庫としてフォルダを開く」で `ai-secretary` を選び直す |
| つないだはずの道具が使えない | Claude Code を開き直す。動いているセッションには、あとから足したものは出てきません |
| ターミナルの開き方が分からない（Mac） | Claude に「Mac の VS Code でターミナルはどこにあるの？」と聞く。Control＋`（バッククォート）でも開きます |
| Python が要る、と言われた | 入っていません。Claude Code に「Python を入れて」と頼む |
| 入れた NotebookLM が、思っていたものと違う | 同じ名前のものが複数あります。`notebooklm-mcp-cli` を名指しで入れ直す |
| インストールが終わらない（Mac） | OS を古いまま放置していると、開発ツールの再インストールから始まって数十分かかります |

**人に見せながら設定する日は、前もってこの4つを確認しておくと安全です。**
① OS が最新か ② Python が入るか ③ VS Code のターミナルが開けるか ④ Claude の拡張が有効になっているか。
講座では、1人の環境が壊れていたために、その回のメニューが1つ丸ごと流れました。

## よくある質問

### 情報が漏れませんか？

**クラウドに送っている、という事実は変わりません。** 学習に使わせない設定はありますが、それでトレードオフが
消えるわけではありません。お客様の情報は送らない・自分の情報は許容する、のように線はご自分で引くことになります。
送る前にマスクしてから渡す、という方法もあります。

### 秘書の記憶は、どこにあるのですか？

**フォルダの中のマークダウン（.md）ファイルです。** チャットの履歴ではありません。
だからフォルダごと別のパソコンに移せば、そのまま続きから始められます。

### VS Code を入れると、いままでの Claude の履歴も移りますか？

**移りません。** ブラウザやアプリで話した履歴と、VS Code の中の Claude Code は、別のところに溜まります。

### コードが書けなくても、できますか？

**できます。** 講座の4回を通して、コードは1行も書いていません。要るのは、書かれていることを読める日本語の力です。
分からない画面が出たら、その画面のことを Claude 自身に聞いてください。

### メールの請求書を、月別のフォルダに落としたい

MCP だけではできません。[メールの添付をフォルダに入れる](#つないだあと-2-メールの添付をフォルダに入れる) の手順になります。
プログラムが1本要りますが、書くのは秘書です。

### LINE はつなげますか？

**個人の LINE はつなげません。** 法人向けのもの（LINE 公式アカウント）なら可能性があります。

### iPhone の中の写真も整理できますか？

**パソコンの中にある写真だけです。** iPhone の中を直接さわることはできません。

### iPad でもできますか？

**入れるところは、パソコンが要ります。** VS Code・Claude Code・Obsidian を入れる作業は iPad ではできません。

ただ、**入れたあとなら iPad だけでも続けられます。**

- Claude のアプリ（iPad にも同じ iOS 版が入ります）の **Code** から話しかける
- GitHub のプライベートリポジトリにしておくと、iPad から話した内容も**ファイルになって積み上がります**
- 読むのは Obsidian の iPad 版。同じフォルダを開けば、パソコンと同じ画面で見られます

まずはパソコンで一周してから設定してください。アプリに **Code** タブが出ないときは、プランの条件を確認してください。

### Codex ではだめですか？

**だめではありません。** どちらもファイルを書く AI で、マークダウンで出すという点は両方できます。違うのはこの3つです。

- **読む指示書の名前が違う** — Claude Code は `CLAUDE.md`、Codex は `AGENTS.md`。このキットは `CLAUDE.md` 前提なので、そのままでは読まれません
- **置き場所の考え方が違う** — Claude Code は手元のフォルダを直接さわるのが基本。Codex はクラウドで動かすのが主軸です
- **乗り換えても、記録は無駄になりません** — 溜まるのはただのテキストなので、どちらのツールでも読めます

この講座は Claude Code に合わせて作ってあります。慣れてから乗り換えるのは自由です。

## テンプレートが新しくなったときは

つまずくところが見つかるたびに直しているので、あとから中身が変わります。新しくしたいときは、Claude Code にこう言ってください。

> 更新して

秘書が最新の指示書とホームを取りに行き、**あなたが書いた記録（TODO・決めたこと・アイデア）には触れずに**、変わったところだけを取り込みます。指示書をご自分の仕事に合わせて書き換えていれば、それも残します。

ZIPを落とし直しても構いませんが、**すでに使い始めた方は入れ直さないでください。** `secretary/` の中はもうあなたの記録です。上から重ねると消えます。まだ一度も話しかけていないなら、フォルダごと置き換えて問題ありません。

## 安全上の注意

- **実データを入れたフォルダ・リポジトリを Public（公開）にしないでください。** TODOや記録には取引先名・金額などが入ります。GitHubに置く場合は必ず Private で
- 秘書はファイルを読み書きします。機密を扱う場合は、このフォルダに何を入れるかを自分で決めてください
- **アプリパスワード（16桁）や API キーを、フォルダの中やファイルに書き込まないでください。** メール全体を読める鍵です。
  使わなくなったら、発行した画面から取り消してください
- 画面共有・配信をしながら操作するときは、映るものに気をつけてください。アプリパスワードの入力画面、
  フォームの自動入力（氏名・住所・電話番号）が、そのまま相手に見えます
