# AI社員1号「秘書」スターターキット

AIに秘書役の社員になってもらうための、いちばん小さなテンプレートです。

中身は**フォルダと日本語の指示書（CLAUDE.md）だけ**で、プログラムは入っていません。

講座「社長はひとり。社員は全員AI」の配布教材です。

## この秘書ができること

- **TODO管理** — やることを預かり、翌日に持ち越し、「今日やることは？」に答える
- **自動記録** — 会話の中で決めたこと・学んだことを、言わなくてもファイルに残す
- **相談相手** — 壁打ちや考えの整理に付き合い、決まったことだけ記録する

ポイントは、チャットの履歴ではなく**ファイルに残る**こと。だから明日も、来月も、続きから始められます。

## 動かすまでの3ステップ

### 1. ダウンロードして、置き場所を決める

**→ [ai-secretary.zip をダウンロード](https://github.com/ray09210/ai-secretary/releases/latest/download/ai-secretary.zip)**（GitHubのアカウントは要りません）

落ちてきたZIPを右クリックして **「すべて展開」**。`ai-secretary` というフォルダができます。

そのフォルダを、次の場所へ移動してください。

```
Windows   C:\Users\<あなたのユーザー名>\ai-secretary
Mac       ~/ai-secretary
```

**このあと開くのは、ここだけです。** Claude Code も Obsidian も、同じこのフォルダを開きます。

（ドキュメントやデスクトップの中は避けてください。OneDrive の同期とぶつかることがあります）

GitHubアカウントをお持ちの方は、このページの **「Use this template」→「Create a new repository」** で自分のリポジトリとして作ることもできます。その場合は必ず **Private** を選んでください。

### 2. Claude Code でフォルダを開く

Claude Code をまだ入れていない方は、[claude.com/claude-code](https://claude.com/claude-code) からインストールしてください。

インストール済みなら、手順1で置いた **`ai-secretary`** フォルダを開くだけです。

- ターミナルの場合: `cd ai-secretary` で移動して `claude` と入力
- VS Code の場合: ファイル →「フォルダーを開く」で `ai-secretary` を選び、Claude Code 拡張を起動

### 3. 話しかける

最初のひとことは、これで:

> おはよう。今日やることを教えて

サンプルの会社（架空の宿「うみねこ荘」「やまぶき亭」）のTODOを繰り越して答えてくれたら、成功です。

そのあと、こう言ってみてください:

> サンプルを消して、私の会社に合わせて

秘書があなたの事業について質問して、指示書を書き換えてくれます。

### 4. Obsidian で開く（記録を見る側）

秘書が書いた記録は、ただのテキストファイルです。**Obsidian の設定は、このテンプレートに入れてあります。**
新しく保管庫を作る必要はありません。場所を教えるだけです。

1. Obsidian を開く
2. **「フォルダを保管庫として開く」** を選ぶ（「新規保管庫を作成」ではありません。ここだけ注意）
3. **`ai-secretary`** を選ぶ（Claude Code で開いているのと同じフォルダです）

フォルダは1つ、窓が2つあるだけです。Claude Code が書いて、Obsidian で読みます。

開くと **`Home`（ホーム）** が出ます。秘書が書いたものが、TODOも記録もアイデアも区別なく、**新しい順に並ぶ画面**です。「昨日なにを話したか」を探すときは、まずここを見てください。表は自動で作られるので、あなたが書き足すものはありません。

設定する画面は出てきません。もし左側に何も並ばなかったら、`CLAUDE.md` と `secretary` が入っていないフォルダを選んでいます。手順1に戻ってください。

Obsidian は、自分で書くためのアプリとしては使いません。**書くのは秘書、読むのはあなた**です。
同期の設定もプラグインも要りません。

## フォルダの中身

```
ai-secretary/
├── .obsidian/               ← Obsidianの設定（さわらなくて大丈夫）
├── Home.md                  ← ホーム。書いたものが新しい順に並ぶ
├── CLAUDE.md                ← 会社のルール（全AI社員共通）
└── secretary/
    ├── CLAUDE.md            ← 秘書の指示書（役割・口調・仕事の手順）
    ├── todos/               ← 日々のTODO（YYYY-MM-DD.md）
    ├── notes/               ← 決めたこと・学んだことの記録
    └── inbox/               ← アイデア・あとで考えることの置き場
```

CLAUDE.md は Claude Code が起動時に自動で読むファイルです。ここに日本語で書いたことが、そのまま秘書の行動になります。**書き換えれば秘書が変わります。** まずは口調や記録のルールをいじってみてください。

社員を増やしたくなったら、`secretary/` の隣にフォルダを作って CLAUDE.md を1枚置くだけです（例: `keiri/` に経理の指示書）。同じ種類の仕事が続くと、秘書のほうから「部署を作りましょうか」と提案してきます。

## テンプレートが新しくなったときは

つまずくところが見つかるたびに直しているので、あとから中身が変わります。ただし、**すでに使い始めた方は入れ直さないでください。** `secretary/` の中はもうあなたの記録です。上から重ねると消えます。

- **まだ一度も話しかけていない** → フォルダごと、新しいものに置き換えて構いません
- **もう使っている** → ZIPをもう一度ダウンロードして、**欲しいファイルだけ**を自分のフォルダにコピーしてください。`Home.md` のように1枚で完結するものは、置くだけで動きます
- **フォルダ名が `ai-secretary-starter-main` のまま** → `ai-secretary` に変えておくと、この説明と一致します（変えなくても動きます）

## 安全上の注意

- **実データを入れたフォルダ・リポジトリを Public（公開）にしないでください。** TODOや記録には取引先名・金額などが入ります。GitHubに置く場合は必ず Private で
- 秘書はファイルを読み書きします。会社の機密を扱う場合は、このフォルダに何を入れるかを自分で決めてください
